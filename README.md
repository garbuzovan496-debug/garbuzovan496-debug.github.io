# 🧠 Контекст.Бюро

Локальный анализатор текста: поиск смысловых несоответствий и логических аномалий в `.txt` файлах.

**Демо:** https://garbuzovan496-debug.github.io

## 📌 Что делает проект

«Контекст.Бюро» — это браузерный инструмент, который помогает найти **ошибки и несоответствия** в больших текстах. Работает полностью локально, без сервера, на чистом JavaScript.

Как это работает:

1. Вы загружаете `.txt` файл.
2. Система разбивает текст на предложения.
3. Делает векторный поиск (эмуляция TF-IDF) по запросу.
4. Находит три ближайших по смыслу фрагмента.
5. Формирует ответ **строго по контексту** — без домыслов.
6. **Подсвечивает красным** логические аномалии и несостыковки (например, когда числа или факты в разных частях текста противоречат друг другу).

## 🎯 Задача

Помочь редакторам, аналитикам и копирайтерам быстро находить:

- противоречия в цифрах и фактах;
- логические несоответствия между частями текста;
- места, где нарушена связность изложения;
- ответы на конкретные вопросы строго по загруженному тексту.

## 🛠️ Технологии

- HTML, CSS, JavaScript (без фреймворков)
- Локальная загрузка `.txt` через FileReader API
- Синтаксический парсинг на предложения
- Векторный поиск (эмуляция TF-IDF)
- Детекция аномалий через сравнение числовых и смысловых сущностей
- Всё работает офлайн — данные не покидают браузер

## 🚀 Как пользоваться

1. Откройте https://garbuzovan496-debug.github.io
2. Нажмите **«Выбрать .txt файл»** и загрузите текстовый документ.
3. Дождитесь сканирования — система разобьёт текст на фрагменты.
4. Введите запрос в поле нейро-диалога.
5. Получите ответ по контексту; аномалии будут подсвечены красным.

## 🔍 Пример работы

- Загружаем договор, где в одном разделе указана сумма 10 000 ₽, а в другом — 100 000 ₽.
- Задаём вопрос: «Какая сумма указана в договоре?»
- Система находит оба фрагмента и **подсвечивает несоответствие**.
