  # 🤖 КОНТЕКСТ.БЮРО // TRON PROTOCOL

Автоматическая классификация и маршрутизация заявок с помощью нейросети

## 📊 Описание проекта

Прототип системы для автоматической обработки входящих заявок поддержки. Решение разработано на основе реального ТЗ с фриланс-биржи eText (бюджет 30 000₽).

## 🎯 Задача

Автоматизировать классификацию и маршрутизацию входящих обращений в службу поддержки, чтобы исключить ручную сортировку и ускорить обработку заявок.

## 🛠 Технологии

- **Python 3.12+**
- **PyTorch 2.0+**
- **HuggingFace Transformers**
- **XLM-RoBERTa**
- **Pandas, NumPy, Scikit-learn**
- **Gradio** (для веб-демо)
- **Google Colab**

## 🚀 Быстрый старт

1. Откройте `AI_Ticket_Router.ipynb` в Google Colab
2. Запустите первую ячейку для автоматической установки всех библиотек
3. Следуйте инструкциям в ноутбуке

##  Веб-интерфейс

Проект включает демонстрационный сайт в стиле "TRON PROTOCOL" с неоновым дизайном и адаптивной вёрсткой.

## 📈 Результаты

- Точность классификации: **92.0%** (Accuracy)
- F1 Score: **91.8%**
- Поддержка мультиязычности: **RU, EN, DE**
- 10 категорий заявок
